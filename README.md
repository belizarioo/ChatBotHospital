# 🏥 ChatBot Hospital

ChatBot hospitalar desenvolvido em C# Windows Forms com integração de IA (Gemini).
Projeto desenvolvido para estudo próprio.

## 💻 Tecnologias utilizadas
- C# / .NET 8
- Windows Forms
- API Gemini (Google AI)
- JSON para base de respostas

## ✨ Funcionalidades
- Tela inicial com identificação do paciente
- Respostas automáticas por palavras-chave
- Integração com IA para perguntas não mapeadas
- Histórico de conversa salvo automaticamente

## 📁 Estrutura do projeto
- **Models** - Classes de dados
- **Services** - Lógica do chatbot e integração com IA
- **Data** - Base de respostas em JSON
